This project runs through Flask and so utilizing VS Code's HTML preview feature will cause the project to not work correctly.
In order to run the project on flask first:
1. Import the repository into VS Code and keep same file hierarchy
2. Make a Terminal in VS Code and move into the project folder
3. run "pip instal flask" in the terminal
4. then run "python game.py"
5. In the bottom right corner a window saying "Your application running on port 5000 is available." Click the Open In Browser Button
6. The game should be opened on a Flask server in the browser. To end the game close the tab and while in the VS Code terminal press Ctrl + C
